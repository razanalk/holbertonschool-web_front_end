# CSS Advanced

## Overview

This project focuses on building modern, responsive web interfaces using advanced CSS concepts and best practices. It covers essential styling techniques, layout systems, animations, and reusable design patterns.

## Topics Covered

- CSS Selectors
- CSS Properties and Values
- Block vs Inline Elements
- CSS Reset
- CSS Variables (Custom Properties)
- Inline, Internal, and External CSS
- Grid Systems with Floats
- Web Fonts and SVG Icons
- Pseudo-Classes and Pseudo-Elements
- Backgrounds and Gradients
- CSS Animations
- 2D and 3D Transformations
- Vendor Prefixes

## Requirements

- All files must be interpreted in **Chrome (version 78.x)**.
- All files must end with a new line.
- Every file must begin with a comment describing the task.
- All HTML and CSS code must pass the **W3C Validator**.
